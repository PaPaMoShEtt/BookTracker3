#Training Planner

**Автор:** Урядов Владислав
**Язык:** Python 3.x

## Описание

"Training Planner" — это простое десктопное приложение для ведения дневника тренировок. Оно позволяет добавлять, просматривать, фильтровать и сохранять данные о тренировках в структурированном виде.

## Возможности

-   [ ] **Интуитивный GUI:** Удобный интерфейс для ввода данных.
-   [ ] **Строгая валидация:** Проверка формата даты и числовых значений длительности.
-   [ ] **Гибкая фильтрация:** Поиск тренировок по типу и дате.
-   [ ] **Persistence:** Сохранение истории тренировок в локальный файл `trainings.json`.
-   [ ] **Версионирование:** Проект управляется с помощью Git.

## Технологии

-   **Python:** Основной язык программирования.
-   **Tkinter:** Библиотека для создания графического интерфейса.
-   **tkcalendar:** Расширение для удобного выбора даты.
-   **JSON:** Формат для хранения данных.
-   **Git:** Система контроля версий.

## Инструкция по запуску

1.  Убедитесь, что у вас установлен Python 3.7 или новее.
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите приложение:
    ```bash
    python main.py
    ```

## Примеры использования и тесты

1.  **Тест на некорректный ввод:**
    -   *Действие:* В поле "Длительность" ввести текст "сорок пять" или отрицательное число "-5".
    -   *Ожидаемый результат:* Появляется всплывающее окно с ошибкой "Некорректный ввод данных", запись не добавляется в таблицу.

2.  **Тест на фильтрацию:**
    -   *Действие:* Добавить несколько тренировок разного типа ("Кардио", "Силовая"). В фильтре типа выбрать "Кардио" и нажать "Применить".
    -   *Ожидаемый результат:* В таблице отображаются только записи с типом "Кардио".

3.  **Тест на сохранение/загрузку:**
    -   *Действие:* Добавить тренировку -> Нажать "Файл" -> "Сохранить". Закрыть приложение. Запустить снова -> Нажать "Файл" -> "Загрузить".
    -   *Ожидаемый результат:* Данные из файла успешно загружены в таблицу, тренировка отображается на экране.
