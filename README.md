# Training Planner

Автор: Урядов Владислав

## Описание
Приложение для планирования тренировок с возможностью добавления, фильтрации и сохранения данных.

## Возможности
- Добавление тренировок.
- Фильтрация по типу и дате.
- Сохранение и загрузка данных в JSON.

## Примеры использования
1. Введите дату, тип и длительность тренировки.
2. Нажмите "Добавить тренировку".
3. Используйте фильтры для поиска нужных записей.
4. Сохраните данные через меню "Файл" -> "Сохранить".
5. Загрузите данные через меню "Файл" -> "Загрузить".
